# Burger Hut

Restaurant ordering (Next.js).

## Deploy (Vercel + GitHub)

- **Production**: push to `main` → automatic deploy when the repo is connected in Vercel.
- **Details**: [docs/VERCEL_DEPLOY.md](docs/VERCEL_DEPLOY.md) (domains, env vars, redeploy, CLI).
- **Secrets**: use Vercel Environment Variables only; never commit `.env.local`. See `.env.example`.
